# PagarPe SaaS - User & Role Management Video Script

**Video Title:** PagarPe SaaS me Users aur Roles Kaise Manage Karein
**Target Audience:** Super Admin and Admins using the PagarPe SaaS Application.

---

## 1. Introduction (0:00 - 0:30)

"Hello everyone! Aaj ke is video mein hum dekhenge ki PagarPe SaaS application mein 'User Management' aur 'Role Management' ko kaise configure kiya jata hai. Ek company mein alag-alag log alag-alag roles play karte hain, jaise HR, Manager, ya Admin. Is software ki madad se aap specific roles banakar unhein limited ya full access (permissions) de sakte hain, taaki security aur privacy maintain rahe. Chaliye dekhte hain."

---

## 2. Role Management & Permissions (0:30 - 1:30)

"Sabse pehle aate hain 'Roles' par. Naya role create karne ke liye 'Add Role' par click karein.
Yahan aap role ka naam de sakte hain, jaise 'HR Manager' ya 'Team Lead'.
Iske baad sabse main part aata hai Permissions ka. 
Yahan aap select kar sakte hain ki yeh role kaun se modules dekh sakta hai, kaun se forms edit kar sakta hai, aur kya delete kar sakta hai.
Sirf zaroori permissions check karein aur 'Save' kar dein. Aapka custom role create ho jayega."

---

## 3. User Management & Adding Users (1:30 - 2:30)

"Roles set karne ke baad, hum 'User Management' section mein jayenge jahan se naye users add kiye jate hain.
'Create User' button par click karein. Yahan us person ka naam, mobile number,  email, password aur role fill karein.                                             
Is role ko assign karne se, is user ko apne account mein utna hi access milega jitni permissions humne us role ko di thi.
Save karte hi naya user system mein add ho jayega aur apne credentials se login kar payega."

---

## 4. Conclusion / Outro (2:30 - 3:00)

"Toh dosto, yeh tha PagarPe mein Users aur Roles ko manage karne ka asaan tarika. Is access control (permission) feature se aapka data puri tarah safe rehta hai aur wahi data show hota hai jo jiske liye allowed hai.
Agar aapko is feature ko lekar koi bhi query ho, toh comment karein ya support team se connect karein. Channel ko subscribe zaroor karein! Milte hain next video mein."

--- 
**Note:** Aap is script ko apne screen options aur permission list ke hisaab se customize kar sakte hain.
