# PagarPe SaaS - Leave and Holiday Management Video Script

**Video Title:** PagarPe SaaS me Leaves aur Holidays Kaise Manage Karein
**Target Audience:** Admin, HR, and Managers using the PagarPe SaaS Application.

---

## 1. Introduction (0:00 - 0:30)

"Hello everyone! Aaj hum dekhenge ki PagarPe application mein 'Leave and Holiday Management' module ko kaise use kiya jata hai. Kisi bhi company mein holidays set karna aur employees ki (leaves) track karna ek zaroori hissa hota hai. Is software ke through aap company holidays add kar sakte hain, aur employees application me se  easily leave apply kar sakte hain jisko HR turant approve ya reject kar sakte hain. Chaliye dekhte hain."

---

## 2. Holiday Setup (0:30 - 1:15)

"Sabse pehle aate hain 'Holidays' par. 
- add holiday pe click kr na he usake ander holiday name,  holiday type , select date and description usake bad holiday status ke bad add holiday button pe clic kare . 
- Yeh holidays automatically sabhi employees ke dashboard aur attendance mein reflect ho jate hain, 
- yaha se ham calender view and list view bhi dekh sak te he ."

---

## 3. Leave Application (1:15 - 2:00)  

"Ab baat karte hain Leaves ki. Agar kisi employee ko chhutti chahiye, toh woh application ke through Leave Apply kar sakta hai.
- Saath hi, HR ya authorized user kisi bhi employee ke liye manually Leave Add bhi kar sakte hain.
- Leave apply ya add karne ke liye, sabse pehle Employee select karein.
- Uske baad Leave Type select karein, jaise Sick Leave, Casual Leave ya Paid Leave.
- Ab chhutti ki Start Date aur End Date select karein, yani employee ko kis date se kis date tak leave chahiye.
- Agar leave Paid hai, toh Paid Leave ka checkbox select karein. Agar checkbox select nahi kiya gaya, toh leave Unpaid consider ki jayegi.
- leave ka valid reason enter karein aur Submit par click karein.
- Is tarah, employee ki leave request ya manual leave ko easily manage aur maintain kiya ja sakta hai. 

---

## 4. Leave Status & Approvals (2:00 - 2:45)                  
"Employee ke leave apply karte hi, HR ya Admin ke paas request chali jati hai, jise woh 'Leave Status' section mein dekh sakte hain.
- Is page par sabhi employees ki Pending, Approved, Rejected aur Cancelled leaves ki list show hoti hai.
- HR yahan se request review kar sakte hain. Agar sab theek hai toh 'Approve' par click karein, warna reason dekar 'Reject' kar sakte hain.
- Approve hote hi employee ke leave balance se chhutti deduct ho jati hai"

---

## 5. Conclusion / Outro (2:45 - 3:15)

"Toh dosto, yeh tha PagarPe SaaS mein Leaves aur Holidays ko manage karne ka asaan tarika. Is module ki madad se leave tracking completely transparent aur paperless ban jati hai.
Agar aapka koi sawaal ho toh comment karein ya support team se contact karein. Video dekhne ke liye shukriya, aur channel ko subscribe karna na bhoolein!"

--- 
**Note:** Aap is script ko apni UI screens aur buttons ke hisaab se customize karke apna voiceover de sakte hain.
